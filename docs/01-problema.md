# 01 · Problema y solución

## Problema

Muchas pequeñas y medianas empresas colombianas coordinan inventarios, ventas y clientes con hojas de cálculo o registros en papel. Cuando esos procesos se separan, es fácil cometer errores en existencias, perder tiempo buscando datos y no tener una lectura rápida del desempeño del negocio.

## Solución

GestPyme reúne en una aplicación web los módulos cotidianos de productos, ventas, clientes e informes. Una venta registrada valida existencias y las descuenta en una única operación de base de datos. El panel resalta las métricas del día y del mes, los productos por reponer y los artículos más vendidos.

## Público

Propietarios, administradores y vendedores de una Pyme que necesitan una herramienta sencilla, en español y utilizable desde un navegador moderno.

## Alcance

GestPyme es una aplicación web adaptable a móvil, pero no una aplicación móvil nativa. No incluye facturación electrónica DIAN, pagos en línea, gestión multiempresa ni servicios pagos. GitHub Pages sirve el frontend y Supabase ofrece autenticación y base de datos en su plan gratuito sujeto a sus límites vigentes.
