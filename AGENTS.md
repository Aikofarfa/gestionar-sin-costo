# Instrucciones del proyecto para agentes

## Frontend y UI

- Para cualquier trabajo que cree, edite o revise HTML, CSS, JavaScript o componentes de frontend, leer y seguir [`DESIGN.md`](./DESIGN.md).
- `DESIGN.md` es la fuente de verdad visual de GestPyme: usar sus tokens y recetas para toda nueva interfaz y al tocar componentes existentes.
- Antes de introducir una variación de color, tipografía, espaciado, radio, borde, sombra o movimiento, comprobar si puede resolverse con los tokens existentes. Si de verdad hace falta una nueva decisión, documentarla en `DESIGN.md` y reutilizarla.
- Mantener la funcionalidad y arquitectura existentes; una petición de estilo no autoriza a inventar módulos, cambiar flujos de negocio o añadir servicios de pago.
- Conservar accesibilidad, responsive design, texto en español claro y semántica HTML.
- No copiar código o activos de repositorios de terceros sin revisar sus licencias y atribución.
